# DHS model datasets

The model datasets from the DHS website in a \`data.frame\` that is
analogous to those returned by \`get_available_datasets()\`

## Usage

``` r
data(model_datasets)
```

## Format

A dataframe of 36 observations of 14 variables:

`model_datasets`: A dataframe of model datasets

- "FileFormat"

- "FileSize"

- "DatasetType"

- "SurveyNum"

- "SurveyId"

- "FileType"

- "FileDateLastModified"

- "SurveyYearLabel"

- "SurveyType"

- "SurveyYear"

- "DHS_CountryCode"

- "FileName"

- "CountryName"

- "URLS"
